# Data Analysis Scripts

This folder contains Python scripts used to analyze ESPN Fantasy API responses and generate the documentation.

## Scripts

### `analyze_views.py`
Analyzes the structure of all JSON response files to identify:
- Top-level keys in each response
- Presence of members, teams, schedule data
- Team object structure
- File sizes

**Usage:**
```bash
cd data_analysis_scripts
python analyze_views.py
```

**Output:**
- Console summary of all JSON files
- `analysis_results.json` - Detailed analysis results

---

### `detailed_analysis.py`
Performs deep analysis to check availability of specific data points:
- Owner names (display names and first/last)
- Team records, win rates, streaks
- Rosters and player information
- Matchup scores

**Usage:**
```bash
cd data_analysis_scripts
python detailed_analysis.py
```

**Output:**
- Console summary with availability matrix
- `detailed_analysis_results.json` - Detailed findings

---

## Running the Scripts

Both scripts expect to be run from within the `data_analysis_scripts` directory and will look for JSON files in the `../sample_data/` directory.

**From the project root:**
```bash
cd espn_fantasy_api/data_analysis_scripts
python analyze_views.py
python detailed_analysis.py
```

**From the data_analysis_scripts directory:**
```bash
python analyze_views.py
python detailed_analysis.py
```
